Get ready
  • 🎧
    Apart: wear wired earphones so the other voice doesn't leak into your mic. Bluetooth earbud mics are low quality.
  • 🪑
    Same room: skip the earphones. Tap Speaker off on both phones and sit at least 1–2 m (3–6 ft) apart. The speaker doesn't affect your mic or your recording.
  • 📏
    Hold the phone 15–20 cm (6–8 in) from your mouth, a little to the side, so you talk across its bottom mic. That stops "p" and "b" pops.
  • 🛋️
    Pick a quiet, soft room. Turn off fans and AC. Keep the phone still.

How a call works
  1. Both phones open this page in Chrome and type a name.
  2. One taps Start a new call and texts the 4-letter code to the other.
  3. The other types the code and taps Join call. Both screens say Connected.
  4. Either taps Start recording. Both phones count down 3-2-1 and record.
  5. Either taps Stop & save. Each phone saves its own file.
Troubleshooting

Won't connect? Put both phones on Wi-Fi (some mobile networks block direct calls). Check the code and keep the first phone on the call screen. If the call drops, recording keeps going and the page reconnects by itself.

Screen off? Recording runs on the audio thread and is saved every second, and Chrome usually keeps a live call going with the screen off. Android can still pause Chrome to save battery, so do a 2-minute test first. If the file comes out short, keep Keep the screen on switched on and turn the brightness down. Set Chrome's battery use to Unrestricted (Settings › Apps › Chrome › Battery).

Install as an app: tap Install at the top, or Chrome ⋮ › Add to Home screen. It opens full screen with its own icon. Screen-off behaviour stays the same.
